# OpenWrt SSH Tunnel

Пакет добавляет в LuCI → **Сеть → Интерфейсы → Добавить интерфейс** протокол
**SSH Tunnel**. Создаваемый интерфейс не устанавливает маршрут по умолчанию;
его можно выбрать в Podkop как выходной интерфейс.

Это SSH VPN с TUN, реализованный в существующем проекте. Это не `ss://`
Shadowsocks. Интерфейс OpenWrt соединяет локальный TUN с тем же обработчиком,
который использует Windows-клиент.

Для сборки нужен SDK именно от OpenWrt 25.12.5 для `mediatek/filogic`
(`aarch64_cortex-a53`). Скопируйте каталог `luci-proto-ssh-tunnel` в
`package/` SDK, включите пакет через `make menuconfig` и соберите его командой
`make package/luci-proto-ssh-tunnel/compile V=s`. Устанавливайте IPK вместе с
зависимостями и только на совместимую версию/архитектуру OpenWrt.

На первом подключении пакет запускает `install-server.sh` через SSH. Нужен
доступ по SSH пользователем `root` на Debian/Ubuntu. В форме можно указать
пароль либо путь к уже установленному на роутере приватному ключу. Первый
ключ SSH-сервера автоматически принимается в `known_hosts` пользователя root.

Это исходный пакет, а не готовый IPK. Его ещё нужно собрать в SDK и проверить
на роутере с указанной версией прошивки. Созданный интерфейс использует адреса
`172.31.255.2/30` и `172.31.255.1`; на удалённом сервере одновременно
поддерживается одно подключение, как и в Windows-клиенте.
